【操作步驟】
1. 解壓縮本 ZIP。
2. 在 GitHub Desktop 中開啟倉庫 lw56532，點選「Show in Explorer」。
3. 把解壓縮後的兩個檔案「01_加入返回總首頁.bat」與「install_home_button.ps1」複製到 lw56532 最外層，和 index.html、quiz.html 放在同一層。
4. 雙擊「01_加入返回總首頁.bat」。
5. 視窗出現「Complete: 5 modified」表示五個網頁都已加入按鈕。按任意鍵關閉視窗。
6. 請將剛才複製進 GitHub 資料夾的 .bat 和 .ps1 檔案刪除（這是電腦用更新工具，不需要放上網站）。
7. 回到 GitHub Desktop，應該只看到 5 個已修改 HTML 檔案。
8. 左下角 Summary 輸入：「新增返回學校總首頁按鈕」；按「Commit 5 files to main」。
9. 最後按「Push origin」，然後重新整理題庫網站（可按 Ctrl+F5）。
