## 功能

- 首頁選五章，章節練習可按原順序或隨機，亦可一次練 20/50/全章。
- 選項可隨機排列；**含原圖題目固定原 PDF 選項順序**，避免圖中 A～D 標示錯位。
- 練習模式：答對顯示綠色、答錯顯示紅色，右側題號同步顯示；錯答時正解也亮綠色。
- `1`、`2`、`3`、`4` = 畫面 A～D；`→` 或滑鼠右鍵 = 下一題；`←` = 上一題。
- 50 題模擬考試：五章混合隨機抽題，答對 **+2**、答錯 **-1**、未答 **0**；限時可選 30/50/60 分鐘或不限時。考試中不揭露正解，交卷才公布。
- 錯題本、重練、紀錄存本機、歷史成績 CSV 匯出。
- 頁面在手機、平板和電腦上都可操作。

## 上傳至你現有的 GitHub 儲存庫

**目標儲存庫：** <https://github.com/lw56532-tech/lw56532>

此 GitHub 儲存庫的根目錄已經有另一套練習平台的 `index.html`，**不要用這份 `index.html` 覆蓋根目錄**。

1. 解壓縮下載的 `robotics-quiz-github.zip`。
2. 將整個 **`robotics/` 資料夾**加入 `lw56532-tech/lw56532` 儲存庫根目錄，而非只上傳 `robotics/` 裡的 `index.html`。需保留所有 `images/` 圖檔和 `questions.js`。
3. **推薦使用 GitHub Desktop**：Clone repository → 把 `robotics` 資料夾貼到本機儲存庫 → Commit → Push origin。因為有 **663 張圖片**，GitHub 網頁上傳可能不適合一次處理這麼多檔案。
4. 若尚未啟用 Pages：GitHub → **Settings → Pages** → **Deploy from a branch** → `main` / `(root)` → Save。
5. Pages 部署完成後，預計網址為 **https://lw56532-tech.github.io/lw56532/robotics/**。
6. 若要把機器人題庫加進原本平台首頁，可開啟下載包中的 `首頁新增入口.html`，將其中的卡片程式碼貼到 **根目錄** `index.html` 的 `<section class="grid">` 裡其他 `<article>` 後面。

注意：不要把 ZIP 檔本身直接放到儲存庫，GitHub Pages 不會自動解壓縮 ZIP。

## 使用上的限制

這是純前端 HTML。成績、進度、錯題記錄存在學生自己的瀏覽器 `localStorage` 中，**不會自動回傳老師**。清除瀏覽器資料可能使紀錄消失；GitHub Pages 本身無法提供真正的集中登入、監考或防作弊保證。
