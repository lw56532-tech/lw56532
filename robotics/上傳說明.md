# GitHub Pages 部署說明

此壓縮檔包含：
- `index.html`：已加入「工科技藝競賽｜機器人學科題庫」卡片的原學習平台首頁。
- `首頁新增入口.html`：正式可開啟的跳轉網頁。首頁按鈕先連到這個檔案，再自動轉至 `robotics/index.html`。即使瀏覽器停用 JavaScript，仍有 HTML 自動轉頁及手動按鈕。
- `robotics/`：五章 563 題的練習網站及圖片，必須整個資料夾一起上傳。

## 部署至 `lw56532-tech/lw56532`

將解壓縮後三個項目 **放在儲存庫根目錄**（也就是與原來的 `quiz.html` 同一層）：

```
index.html
首頁新增入口.html
robotics/
    index.html
    questions.js
    images/
    ...
```

注意：`index.html` 要取代原首頁，這是經過新增卡片的版本；其他原本的 `quiz.html`、`resistor-capacitor.html` 等原網頁 **保留不刪除**。

GitHub Pages 啟用 main 分支 `/ (root)` 後：

- 主頁：`https://lw56532-tech.github.io/lw56532/`
- 首頁按鈕連到：`https://lw56532-tech.github.io/lw56532/%E9%A6%96%E9%A0%81%E6%96%B0%E5%A2%9E%E5%85%A5%E5%8F%A3.html`

首頁原有其他系統連結仍維持相對路徑，不做修改。

如果僅上傳 `index.html` 而未放入 `首頁新增入口.html` 和 `robotics/`，按鈕會找不到頁面，因此三者需一併上傳。
